## GDPR and DPDP Compliance

This project is compliant with the General Data Protection Regulation (GDPR) and the Data Protection and Privacy Directive (DPDP). The following measures have been implemented to ensure compliance:

1. **Data Minimization**: We collect only the data necessary for the operation of the project.
2. **Data Security**: All data is stored securely and access is restricted to authorized personnel only.
3. **User Rights**: Users have the right to access, correct, and delete their personal data.
4. **Data Breach Notification**: In the event of a data breach, users will be notified within 72 hours.
5. **Data Transfer**: Data is transferred only to third parties that comply with GDPR and DPDP.

For more information, please refer to our [Privacy Policy](./PRIVACY_POLICY.md).
